START HERE

Connect, customize, save.

  1. Connect by USB. Plug your AULA WIN 60 HE MAX directly into your computer. Close other AULA driver tabs or applications.
  2. Open the web driver. Use desktop Chrome or Edge, press Connect and choose WIN 60 HE MAX in the browser picker.
  3. Back up your current setup. Open Backup and download a JSON copy before making large changes.
  4. Apply your settings. Edit a panel and press Apply or Save. The preview alone does not write to the keyboard. Apply becomes gray and disabled after saving, until you change a value. On reconnect, Studio reads the device settings and recognizes a matching preset again.

The app follows your browser language and offers English, Italian, Russian, Spanish and Japanese. Choose a light, dark or system theme after connecting.

MAKE IT YOURS

Configure Rapid Trigger, RGB and key mapping.

01 / RESPONSE

Rapid Trigger & actuation

Adjust per-key actuation, Rapid Trigger press/release sensitivity and dead zones, or select shared global actuation. Check sensor travel in the key tester.

02 / LIGHTING

RGB & per-key colors

Choose static lighting, rainbow or one of 20 firmware effects. Set brightness and speed, or paint individual keys. Apply the draft to save it to the device.

03 / LAYOUT

Key remapping & Fn

Drag keycaps onto either layer, preview and save. Complete empty Fn slots with Delete, F1–F12, navigation and numpad keys. RGB lighting has its own pool for onboard lighting shortcuts.

04 / INPUT

SOCD & advanced actions

Configure opposing-direction pairs, DKS, MPT, Mod-Tap, Toggle, release actions, Rappy Snappy or a macro sequence. Review the firmware limits below.

Additional controls include 125–8000 Hz polling, supported onboard profiles, Super Response, Windows/macOS mode, guided calibration and JSON backup/restore. Controls depend on the device capabilities reported at connection.

PRACTICAL ANSWERS

Common setup questions.

How do I change the AULA WIN60 HE MAX RGB lighting?

Connect, open RGB lighting, choose an effect or static color and press Apply lighting. Brightness and speed use five firmware levels, 0–4. Brightness 0 is dark. To color individual keys, select them, choose a color, press Paint selection and apply.

How do I enable Rapid Trigger?

Open Performance, select the keys and choose Rapid Trigger. Set actuation, press/release sensitivity and dead zones, then apply. The FPS profile in Overview is a convenience preset; review its values before using it.

Why do A/D or WASD send arrows instead of letters?

Use Set Fn arrows in Overview to restore WASD letters on the base layer. This firmware ignores Fn assignments on SOCD-enabled keys. Use Fn + Right Alt / Right Ctrl for left/right while A/D SOCD is active.

Is this the official AULA driver?

No. WIN60 HE Studio is an independent open source interface built with the SparkLink keyboard SDK. It is not affiliated with or endorsed by AULA. You can inspect the code and report problems in the GitHub repository.

Why does the keyboard not appear in the picker?

Check the exact model and USB IDs, use a data-capable cable and close other driver connections. Open the app directly in desktop Chrome or Edge over HTTPS. Linux may need a device-specific HID permission rule.

Can I use SOCD or macros in a game?

Check the game and tournament rules before enabling automated input. Firmware availability does not imply permission in a game or competition.

Does this app update keyboard firmware?

No. Firmware flashing is unavailable until an official image, correct bootloader and recovery procedure have been verified. Do not use firmware for a different AULA model.

KNOW WHAT IS VERIFIED

Current limits and hardware checks.

RGB static and per-key settings completed real USB write/readback/restore checks on the target keyboard. Browser tests exercise the actual application and SDK with an emulated WebHID boundary. These checks do not establish physical macro timing, sensor accuracy or advanced-action behavior.

Macros support one assigned sequence per profile, up to 64 balanced events. The SDK shares a staging buffer. Studio retains original events locally and can export them; arbitrary sequences made in another driver cannot be reconstructed from the binding metadata. Keep the original JSON file.

Back up a working profile before making large changes. See the full user guide and troubleshooting documentation for details.
