# WIN60 HE Studio documentation

WIN60 HE Studio is an independent WebHID configurator for the **AULA WIN 60 HE MAX** magnetic Hall effect keyboard (`1CA2:1902`, vendor interface `FFA0:0001`).

## Use the keyboard configurator

- [Open the web driver](https://primebuild-pc.github.io/aula-win60he-tool/)
- [Public guide and compatibility](https://primebuild-pc.github.io/aula-win60he-tool/guide/)
